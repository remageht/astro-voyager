# Security Policy / Политика Безопасности

## Поддерживаемые версии / Supported Versions

Мы поддерживаем стабильные версии и активно выпускаем исправления безопасности для актуальной ветки разработки:

| Версия | Поддержка безопасности |
| :--- | :--- |
| `v4.8.x` | :white_check_mark: Поддерживается (Active) |
| `v4.7.x` | :white_check_mark: Поддерживается |
| `< v4.7.0` | :x: Не поддерживается |

## Сообщение об уязвимости / Reporting a Vulnerability

Astro-Voyager — это высокопроизводительное C++ приложение, использующее низкоуровневые графические API и файловый ввод-вывод (сериализация сохранений `SaveGame.obj`, загрузка моделей OBJ/GLSL).

Если вы обнаружили:
* Переполнение буфера или уязвимость в парсерах форматов данных;
* Утечку памяти при обработке пользовательских ассетов;
* Сбои в подсистеме шейдеров или безопасности памяти;

Пожалуйста, **не создавайте публичный Issue**. Вместо этого:
1. Воспользуйтесь функцией **GitHub Private Vulnerability Reporting** во вкладке [Security Advisories](https://github.com/remageht/astro-voyager/security/advisories/new).
2. Либо свяжитесь с мейнтейнером проекта через личные контакты профиля GitHub.

Мы стремимся рассматривать все отчеты в течение **48 часов** и выпускать исправления с публикацией подробного Security Advisory.
