## Ритуалы релизов

- Гейты перед релизом: `ctest` (core + gl), static checks, GL-сборка, `--screenshot-all` (референсы байт-в-байт, кроме плановых).
- Версия: `VERSION`, `src/Version.h`, `CMakeLists.txt`, `res/catalog.json`, секция в `CHANGELOG.md`.
- Тег `vX.Y.Z` + GitHub release с двуязычными notes; CI прикрепляет macOS tar.gz / AppImage / windows zip; при необходимости zip пересобирается с тега.
