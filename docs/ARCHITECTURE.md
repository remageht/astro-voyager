# ARCHITECTURE — astro-voyager v1.0.0

## Идея

Развитие `RuCatGH/blackHole`: полноэкранный raytrace-шейдер с RK4-геодезикой
Шварцшильда + путешественник по станциям вместо одной сцены.

Бесшовной вселенной нет осознанно: `Rs=1.0` против парсек ломает float-precision.
Паттерн — Station: телепорт меняет skybox-параметры и шейдер, внутри станции
свободный полет WASD + мышь.

## Модули

### Core (headless, без GPU / GLM / GLFW)
- `Catalog` — builtin-каталог 6 станций, зеркало `res/catalog.json`.
  Контракт: `docs/CATALOG.md`.
- `Camera` — yaw/pitch + forward/right/up, `clampNearHorizon(Rs*1.05)`.
  Своя `Vec3` чтобы core собирался без GLM в CI.
- `Geodesic` — CPU-эталон формул из `shaders/bh.frag`:
  `geodesicAcceleration`, `rk4Step`, `traceRay`.
  Используется в `--demo-geodesic` и unit-тестах.
- `Interaction` — логика захвата курсора, блокировки ввода при фокусе ImGui и clamp камеры у горизонта событий.
- `main` — CLI: `--list`, `--info <id>`, `--demo-geodesic`, `--test-interaction`, `--version`.

### OpenGL Renderer (`ASTROVOYAGER_ENABLE_GL=ON`)
- `Window` — обертка GLFW: создание окна, контекст OpenGL 3.3 Core, VSync.
- `Shader` — загрузка GLSL из файлов, компиляция vertex/fragment, кеширование и установка uniform.
- `Mesh` (`ScreenQuad`, `LineMesh`) — геометрия fullscreen quad (VAO/VBO/EBO) и полилинии созвездий (GL_LINES, GL_POINTS).
- `Cubemap` — 6 граней скайбокса. Процедурный генератор звездного поля и рукавов Галактики с автозагрузкой локального HDR при наличии.
- `SceneManager` — управление сценами и телепортация (`sgra`, `ori`, `qso-3c273`, `uma`, `m31`, `m1`), выбор шейдеров, пресеты качества и установка физических параметров.
- `AppGL` — главный цикл, WASD-перемещение, обзор мышью, интеграция Dear ImGui (HUD со списком станций, комбобоксом пресетов, слайдерами и FPS), захват скриншотов.

## Рендер станций

- `shaders/quad.vert + bh.frag` — Schwarzschild null-geodesic raytracing с численным RK4.
- `shaders/quad.vert + quasar.frag` — core+disk+jets, procedural billboard квазара 3C 273.
- `shaders/lines.vert + lines.frag` — созвездия Orion (`ori`) и Ursa Major (`uma`) через `GL_LINES` и `GL_POINTS`.
- `shaders/quad.vert + galaxy.frag` — галактика Андромеда (`m31`), процедурный спиральный impostor-спрайт с балджем и пылевыми полосами.
- `shaders/quad.vert + nebula.frag` — Крабовидная туманность (`m1`), процедурный impostor-спрайт с пульсаром и волокнами.
- Скриншоты сохраняются в `docs/screens/`.

## Физическая модель Sgr A* и ограничения

- **Метрика Шварцшильда**: статическое сферически-симметричное гравитационное поле ($M > 0$, заряд $Q = 0$, угловой момент $a = 0$).
- **Численное интегрирование**: 4-й порядок Рунге-Кутты (RK4) для нулевых геодезических в натуральных единицах ($c = 1, G = 1, R_s = 1.0$).
- **Критерии останова луча**:
  - Захват горизонтом событий: $r \le R_s \times 1.001 \implies$ абсолютно черный цвет (тень черной дыры).
  - Свободный выход на бесконечность: $r \ge R_{\text{shell}} \implies$ выборка цвета из cubemap звездного неба.
  - Лимит шагов `maxSteps`: фоновое ослабление (dim fallback).
- **Осознанные решения и ограничения модели**:
  - **Метрика Керра**: отсутствует ($a = 0$). Реальный Sgr A* вращается, однако для стабильного вещественного рейтрейсинга и соответствия формулам `RuCatGH/blackHole` используется чистая геометрия Шварцшильда без эргосферы и эффекта Лензе-Тирринга.
  - **Отсутствие искусственного диска в `bh.frag`**: шейдер `bh.frag` реализует строгое гравитационное линзирование звездного фона. Моделирование светящегося аккреционного диска, релятивистского доплеровского биминга и джетов осознанно вынесено в станцию квазара `qso-3c273` (`shaders/quasar.frag`).
  - **Ограничение камеры**: радиус камеры ограничен $R \ge 1.05 R_s$, исключая сингулярности координат и попадание наблюдателя под горизонт событий.
